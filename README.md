# FIRE 40

面向单个家庭的本地优先半退休与财务自由规划工作台。家庭数据、模拟结果、情景和 AI 对话保存在浏览器 IndexedDB；不需要数据库或账号系统。

## 本地启动

```bash
npm install
cp .env.example .env.local
npm run dev
```

打开 <http://localhost:3000>。不配置 OpenAI Key 时，除 AI 顾问外的全部功能仍可使用。

如需 AI，可直接在“设置中心 → 接口提供商与连接凭证”填写 OpenAI 兼容服务的 Base URL、模型名称和 API Key。模型地址和名称保存在本地并进入家庭备份；API Key 只保存在当前浏览器会话。

也可以在 `.env.local` 中提供默认 OpenAI Key，供未填写 Key 时使用：

```text
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-5-mini
```

## Docker

```bash
cp .env.example .env
docker compose up --build
```

Docker 仅运行 Web 服务，没有数据库容器。

## 数据与备份

- 家庭数据仅保存在当前浏览器的 IndexedDB。
- 在“设置中心”导出 JSON 备份；换设备或清理浏览器数据前务必导出。
- 模型地址、模型名称和 AI 对话会随 JSON 备份迁移；AI 顾问会使用最近 12 条对话和已保存情景保持追问上下文。
- API Key 只保存在 `sessionStorage` 并发送到同源 Next.js 代理，不写入家庭数据、对话或备份；关闭浏览器会话后清除。
- 导出的 JSON 是明文文件，请存放在可信位置。
- 长期风险模拟与压力测试只保存输入快照、32 位随机种子、分位路径和摘要指标，不保存 10,000 条原始随机路径。
- 家庭数据或风险参数修改后，历史结果会保留并标记为“已过期”，不会自动覆盖或删除。

## 计算口径

引擎以月为周期：期初投资回报 → 工作及轻工作收入 → 公积金缴存 → 购房事件 → 生活费与房贷 → 现金/投资资产补足 → 现金缓冲与超额投资。资产耗尽后余额保持为零，并记录首次资金不足月份。

默认数据基准月为 2026-10，可投资资产为 181.3 万元；40 万元公积金独立核算，保险已缴保费未被当作现金价值。

## V2.1 风险模拟

- “长期风险模拟”提供 1,000 次快速预览与 10,000 次正式模拟，使用固定种子、稳定 PRNG 和月度对数正态收益模型。
- 默认波动率为 15%，必须由用户确认后才能运行；8% 与 22% 分别作为稳健、进取预设。
- “压力测试”支持单人失业、夫妻失业、退休初期暴跌、轻工作中断、医疗支出、生活费上涨和多重风险。
- 基准与冲击方案复用同一随机序列；AI 只解释已生成的聚合结果，不自行编造资金充足比例。

## V2.2—V2.3 长期现金流与退休决策

- 生命周期页面提供未来 50 年时间线；教育、照护、医疗及一次性费用只有填写后才进入模拟，“已包含”项目不会重复计费。
- 夫妻可分别记录社保、医保、商业保费和养老金假设；只有明确确认的养老金才进入退休收入。
- 支持固定实际金额、固定资产比例、弹性支出和现金缓冲四种退休提取策略，并用同一种子比较资金充足度与生活稳定性。
- 退休风险中心分开显示长期资金、流动性、劳动收入、市场暴露、家庭责任和保障缺口，不生成单一退休评分。
- 退休准备清单支持状态、期限、备注和自定义任务，AI 回答可手动转为准备任务。
